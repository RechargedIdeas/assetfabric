## F1 — Content Pipeline

17. **Procedural G1-Sprite backend** (template humanoid/beast, 6-frame sheet idle/walk/attack) stands in for the 2–4 MB ONNX Tiny model; same generator interface so the ONNX backend can replace it.
18. **Cellular-automata G1-Tile backend** stands in for the ~2 MB NCA model; CMA-ME diversity search deferred. Solvability gate is BFS (A* equivalent on a uniform grid).
19. **DyeWorks procedural = periodic value noise** quantised to a PatternVault ramp + derived normal map; diffusion backends optional later.
20. **Pure-Python PNG codec** (`forge/imaging.py`) instead of Pillow — keeps generators dependency-free on the 2-core/no-GPU node.
21. **Runtime asset loading** (`Image.load_from_file` + `.gdignore`) instead of Godot editor import presets: Godot 4.3 has no headless `--import`, and runtime loading is what F4 hot reload needs. Pixel presets = project-wide nearest filter + per-node `texture_filter`.
22. **`fabric_assets.json` registry** as the Godot binding contract (G-FAB-01 zero manual wiring).
23. **Determinism gate**: committed generated assets must equal regenerated bytes (SHA-256).
24. **SwatchStudio F1 scope** = `forge palette` terminal swatches + colour-blind variants; the live PySide6 tuning panel arrives with the Studio shell.
25. **Sandbox encounter stats** (`data/encounters/sandbox.json`) hand-authored for F1; F2 codegen replaces them.
26. **Autoplay agent + `FABRIC_RESULT` line** as the headless acceptance protocol; recorded in `docs/acceptance-tests/results/`.
27. **Hero/enemy names** (Kael, Emberling) are placeholders pending GAME_SPEC §10 decisions.

## F2 — Codegen + G1-Audio

28. **Roster content** (Kael/Nyra/Bram/Sola base fighters, Vex/Orrin unlockables, Ember Fox/Stone Tortle/Lumen Wisp starter pets, Emberling/Cave Mite/Rock Brute enemies) and every number in `content/roster/` — placeholders pending GAME_SPEC §10 (D-005).
29. **Ability model**: types melee / ranged (hitscan) / aoe / heal / taunt; damage = max(1, round(atk × power − def)); priority = list order.
30. **Growth curve**: linear 12 %/level on hp/atk, 6 % on def, 10 levels.
31. **Tier scaling**: multiplier 1.0 / 1.6 / 3.2 on hp/atk/def.
32. **Pet stacking formula**: cap × (1 − e^(−sum/cap)), plus a 25 % party share — chat required "diminishing returns + hard cap", not the curve.
33. **Codegen output** = JSON game data + `.tres` ability Resources (not generated GDScript classes) — data-driven abilities keep hot reload (F4) simple.

36. **Autoplay leader** hunts the nearest hostile when none is in range (acceptance driver only).

## F3 — GIRT + CascadeHub + micro-LM path + callouts

37. **GIRT backend for F3 = pure GDScript** (`mlp-gdscript`, `persona-bigram`): no ONNX Runtime GDExtension yet. Model files are JSON so they stay ONNX-exportable; the facade (registry, budgets, telemetry, refusal in tick) is the contract ADR-0004 asks for.
38. **P-TargetSelect** features (dist, hp ratio, hp, tier, atk, in-range, threatens-low-ally), K = 4 candidates, MLP 7→12→1 tanh, trained by behaviour cloning on a focus-fire teacher utility (NumPy, seed 4). Teacher weights are ours.
39. **Persona "micro-LM" = per-persona bigram table + LCG sampler with a repetition guard** — a deterministic stand-in for the spec's LoRA micro-LMs until a real small LM backend exists. Exact Python ↔ GDScript parity is a gate.
40. **Callout cache** = persona templates × ally/foe word slots, expanded offline and safety-gated (length, blocklist, unresolved slots); `%ALLY%` resolved at runtime. Personas and lines in `content/personas/personas.yaml` are ours.
41. **Behaviour-tree vocabulary** (selector/sequence/condition/action; leaves is_casting, ally_needs_heal, should_taunt, tactic_defensive, not_threatened, cast_heal, cast_taunt, select_target, engage, regroup, idle) and tree shapes.
42. **Retarget at 10 Hz** (every 6 ticks, or when target dies / focus intent changes) instead of every tick.
43. **Swap advisor scoring**: Δfoe HP − 1.5·Δparty HP + 2·(candidate damage+healing) + 20·candidate HP ratio + 50 if victory; horizon 120 ticks (spec "~2 s"), forward-sim brains at 15 Hz (LOD 4), movement at 60 Hz.
44. **Swap budget**: GAME_SPEC's "< 50 ms" is tracked as a soft target; hard gate is 150 ms. Parallel candidates on WorkerThreadPool with per-thread forks (brain, grid, abilities) — identical results to serial (tested).
45. **Intent grammar** verbs (focus/target/attack/hit, regroup/fall back/retreat, defend/hold, charge/push/go, swap/switch) — closed vocabulary shared with the future Vosk path (ADR-0006).
46. **CascadeHub** topics (`intent`, `callout_request`, `callout`, `dialogue_request`) drained once after each fixed tick, never inside it.
47. **Demo/attract mode**: windowed `--autoplay` plays the encounter script and holds the freeze overlay 90 frames so it can be captured.
