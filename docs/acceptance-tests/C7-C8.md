## Not proven / honest limits

- **No multi-machine run.** Nodes speak HTTP/JSON on loopback. Since 0.7.14 requests and responses are HMAC-signed (fleet secret) and artifacts move as content-addressed blobs (check 9 below), but there is **no encryption** — pin to Tailscale/WireGuard before binding off loopback (INFERENCES C-17, C-95, C-96, SECURITY.md).
- **No real GPU anywhere.** All GPU rungs (`g1-sprite-onnx-tiny`, `g1-tile-nca`, `dyeworks-sdxl/sd15`, `mlp-train-rocm`, `onnxruntime-gdextension`, `opensplat-rocm`, plus C9–C12: `mirror-h264-hw`, `depthanything-v2-onnx`, `meshweaver-sugar`, `gdgs-raster-import`) are `planned` (14 planned rungs); GroundWeave's CPU path is therefore the only path, and runtime demotion is proven on a synthetic ladder, not a real driver failure. Device placement uses simulated adverts.
- **PocketLoom is a client of the fleet (LoomLink offload), not a Kotlin cluster peer.** SPEC wants phones as equal nodes.
- The full 2400-fight balance run and the Godot builds were **not** re-timed on 2 cores (probe is the reduced matrix; F5/F7 stand on their own acceptance). Budgets are generous regression gates (measured times are 10–100× lower), not performance targets.
- If the origin of a batch never comes back, its results are lost to the submitter (peers keep parking them). No origin hand-off/election.
- Large artifacts travel inside the result JSON (base64) — fine for the current assets, not for textures/audio at scale.
