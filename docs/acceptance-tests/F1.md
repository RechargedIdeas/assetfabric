# Acceptance — F1 Content Pipeline

**Fabric delivers:** procedural G1-Sprite, G1-Tile, DyeWorks; validation gates (palette, dims, seamless, solvability, floor ratio, BudgetGate); Godot binding (`fabric_assets.json` + `Fabric` autoload); PatternVault; SwatchStudio CLI.
**Game proves:** playable sandbox — 1 character, 1 tilemap, 1 enemy, 1 attack. (SPEC §13, GAME_SPEC §6.3)

## Procedure

```bash
source .venv/bin/activate
forge build                 # briefs → generators → gates → store → game
git diff --exit-code games/game-zero/assets/generated   # determinism
pytest -q tests/test_f1_pipeline.py tests/test_game_increments.py
forge accept F1             # headless Godot autoplay; writes results/F1.json
```

Play it: `godot --path games/game-zero` (WASD/arrows move, J/Space attack, R restart).
Record frames: `./scripts/capture.sh /tmp/f1 240 --scene=sandbox --autoplay`.

## Criteria

| ID | Criterion | Proof |
|---|---|---|
| F1-GEN | Sprite, tilemap and material briefs generate and pass every gate | `forge build` ok; `test_all_briefs_pass_gates…` |
| F1-PAL | Every sprite/tile pixel is in its PatternVault palette | palette gate |
| F1-SOL | Cave has exactly one entry and exit and a path between them | solvability gate |
| F1-SEAM | Materials tile seamlessly | seamless gate |
| F1-BUD | Each generator stays inside BudgetGate (≤500 ms sprite/material, ≤2 s tilemap) on CPU | budget gate |
| F1-DET | Regenerated bytes equal committed assets (SHA-256) | determinism test |
| F1-FAB | Game loads all content through the registry; nothing wired by hand | `Fabric` autoload; G-FAB-01 precursor |
| F1-PLAY | Headless autoplay: the hero reaches the enemy, attacks land, enemy is defeated | `forge accept F1` → `outcome=victory` |
| F1-DETSIM | The sim is deterministic (same state hash on every run) | `test_sandbox_is_deterministic` |
