# Acceptance — F2 Codegen + G1-Audio

**Fabric delivers:** codegen (roster YAML → `game_data.json` + ability `.tres` Resources), schema + cross-ref + roster-shape gates, derived sprite briefs for every roster unit, G1-Audio chiptune stems (ambient / tension / combat / boss) + SFX.
**Game proves:** first full combat — party of 4 fighters + pets vs. an enemy group; followers and pets act independently. (SPEC §13, GAME_SPEC §6.3)

## Procedure

```bash
forge build                                  # roster → data + sprites; music stems
pytest -q tests/test_f2_codegen_audio.py tests/test_game_increments.py
forge accept F2                              # headless: --scene=combat --autoplay
godot --path games/game-zero -- --scene=combat   # play (J attack, K skill)
```

## Criteria

| ID | Criterion | Proof |
|---|---|---|
| F2-SCH | Roster sources validate against `docs/schemas/roster.schema.json` | schema gate |
| F2-REF | Every ability / palette reference resolves | cross_refs gate (+ negative test) |
| F2-SHAPE | 4 base fighters, 3 starter pets, unlockable roster beyond 4 | roster_shape gate |
| F2-TRES | Every ability ships as a `.tres` Resource and loads in Godot | `tres_loaded == abilities_loaded` |
| F2-SPR | Every fighter / pet / enemy has a generated sprite (no hand wiring) | derived sprite briefs |
| F2-AUD | 4 stems + SFX: no clipping, exact duration, click-free loop seam | audio gates; WAV header test |
| F2-PARTY | Party of 4 + pets beats ≥5 enemies (incl. tier-2) | `forge accept F2` → victory |
| F2-IND | Every fighter dealt damage or healing; every pet dealt damage | F2 check |
| F2-ABL | ≥6 distinct codegen abilities used (melee, ranged, aoe, heal, taunt) | `abilities_used` |
| F2-PET | Pet bonuses stack with diminishing returns + hard cap | `test_diminishing_returns_cap`, builder |
