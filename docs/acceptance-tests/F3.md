# Acceptance — F3 GIRT + CascadeHub + micro-LM path + callouts

**Fabric delivers:** GIRT inference facade (model registry, per-call latency budgets, telemetry, CPU backend), CascadeHub typed message bus, offline-trained target-selection policy (NumPy behaviour cloning → JSON MLP), safety-gated callout cache, persona bigram LM stand-in (offline-trained, deterministic sampler mirrored in GDScript).
**Game proves:** party AI (data-driven behaviour trees + GIRT policy), time-freeze swap with forward-simulated ranked recommendations, typed player intents, callouts, post-combat dialogue. (SPEC §13, GAME_SPEC §4.1, ML_AI_FEATURES)

## Procedure

```bash
forge build                                     # + callouts.json, persona_lm.json, policy_target.json
pytest -q tests/test_f3_ai.py tests/test_game_increments.py
forge accept F3                                 # headless: --scene=party --autoplay
godot --path games/game-zero -- --scene=party   # play: Tab freeze/swap, 1-4 pick, / command, Q tactic, E talk
./scripts/capture.sh /tmp/f3 301 --scene=party --autoplay   # demo mode holds the freeze overlay on screen
```

## Criteria

| ID | Criterion | Proof |
|---|---|---|
| F3-BT | Fighters, pets and enemies run data-driven BTs (`data/ai/behaviour_trees.json`), compiled to int opcodes | `brain == "bt+policy"`, `decisions.bt_ticks` |
| F3-POL | P-TargetSelect MLP (7→12→1) trained offline, holdout acc ≥ 0.85; used in play with 0 budget fallbacks | policy gate; `policy_calls > 0`, `policy_fallbacks == 0` |
| F3-PAR | GDScript MLP == NumPy probe (|Δ| < 1e-3); GDScript LM sampler == Python sampler probes | F3 check (`selftest`, `lm_selftest`) |
| F3-TICK | No LM call inside the combat tick (ADR-0011) | `lm_refused_in_tick == 0` (GIRT refuses + counts) |
| F3-CO | ≥5 callouts from the pre-generated, safety-gated cache | `callouts_total` |
| F3-INT | Typed commands parse through the closed intent grammar and steer the party via CascadeHub | `intents` ≥ 1 (`focus`, `charge`) |
| F3-SWAP | Time-freeze swap ranks all 4 fighters by forward simulation (~2 s / candidate), scores differ, swap happens | `swap_recs` (4, distinct), `swaps` ≥ 1 |
| F3-SWAP-PAR | Threaded ranking identical to serial ranking | `swap_parity` |
| F3-SWAP-MS | Swap advisor ≤ 150 ms hard ceiling; **< 50 ms p95 gated since 0.7.11** on 2 pinned cores over ≥ 10 sampled freeze states (`--scene=swapbench`, `taskset`), threaded == serial, LOD fidelity (shipped top pick in full-fidelity top 2 everywhere, top-1 agreement ≥ 80 %) | `swapbench.*`, `perf.swap_target_met` |
| F3-DLG | Post-combat dialogue replies non-empty, generated outside the tick | `dialogue` |
| F3-WIN | Party wins the `party_ai` encounter | `outcome == victory` |

## Measured (reference box, 8 vCPU Xeon, no GPU, Godot 4.3 headless)

- Policy p95 ≈ 20–30 µs per 4-candidate call; LM p95 ≈ 40–55 µs per utterance (outside tick).
- Swap advisor (0.7.11, pure GDScript, threaded on WorkerThreadPool, 4 candidates × 120 ticks, brains at 15 Hz LOD): **p50 23.0 / p95 39.4 / max 42.2 ms pinned to 2 physical cores of the reference box** over 17 freeze states × 5 reps; 17/17 top-1 agreement with the full-fidelity ranking. Before Q3: ≈ 50–100 ms on 8 vCPU. Hard-gated in `forge accept F3`; FAST mode (pytest/CI) and the GroundWeave probe gate only ceiling/parity/fidelity because GitHub's 2-core runners measure p95 ≈ 63–66 ms — **target not met on that slower CPU** (GDScript threads scale ≈ 1.3×, `docs/perf/gdscript-thread-scaling/`; a native step function is the follow-up).
- All-pairs path table warm-up ≈ 65–105 ms at encounter load (≈3 MB for a 40×22 map).
