# Acceptance — F5 Balance: Monte Carlo, Bayesian tuning, soft-lock detection, save migration

**Fabric delivers:** Monte Carlo balance runner (`forge balance run`, headless Godot workers sharded over CPU cores, common random numbers, Wilson 95 % CIs), Bayesian tuning (`forge balance tune`, Optuna TPE on CPU, knobs bounded by the live-tune limits), soft-lock detection (static statecharts + encounter reachability, runtime stall/timeout detector, mis-tuned probe), versioned Player State save with migrations (Profile / Roster / World layers, v1 → v2 → v3, GDScript ↔ Python parity). (SPEC §13 F5, GAME_SPEC §4.5, §6.2 G-BAL-01, §8)
**Game proves:** **first tier-3 boss cleared, proven by the balance runner** — the Cave Warden (3 HP-threshold phases, summons, enrage) in its G1-Tile boss arena.

## Procedure

```bash
pytest -q tests/test_f5_balance_save.py
forge accept F5                      # boss clear ×2 + save round-trip + G-BAL-01 (2400 fights) + soft-lock probe
forge balance run --seeds 200        # matchup matrix only; exit 1 if G-BAL-01 fails
forge balance tune --trials 12 --seeds 24   # needs the `tune` extra (optuna)
forge balance holdout --seeds 1000   # Q5: per-pair spread on unseen seeds (seed_base 20 000), exit 1 above 3.5 pp (≈ 4 min)
forge balance tune-affinity --trials 6 --seeds 100 --out docs/acceptance-tests/results/F5-tune-affinity.json   # Q5, ≈ 2.5 min
forge softlock                       # static report
forge save inspect <slot0.json>; forge save migrate <old.json> <new.json>
godot --path games/game-zero -- --scene=boss            # windowed; --autoplay for the BT party
```

## Measured (reference box, 8 vCPU, no GPU, Godot 4.3 headless, 2026-11-12)

- G-BAL-01: **2400** boss fights (12 matchups × 200 seeds, seed_base 1000), mean win rate **0.732**, max choice deviation **3.04 pp** (leaders 0.702–0.760, pets 0.718–0.741), **0 soft-locks / timeouts** → **pass**.
- Per-combination spread (soft): **12.7 pp** (kael+lumen_wisp 0.605 … bram+lumen_wisp / nyra+ember_fox 0.855) → **not met**; tracked in TODO as balance debt.
- Balance wall ≈ 109–135 s on 8 workers (≈ 360 ms per fight per worker). Weakest node (2 cores) extrapolates to ≈ 7–9 min.
- Boss clear (acceptance seed): victory in 880 ticks, sim ≈ 250 ms; 3 phases, 2 summons.
- Optuna: `results/F5-tune.json` = 12 trials × 288 fights (24 seeds/matchup, seed_base 50 000), ≈ 2.8 min. At 24 seeds the per-cell SE is ≈ 9 pp, so short studies are noise-dominated; its best point (score 0.197) is **not** applied — the shipped roster values (chosen with the same tuner during development) verify better at 200 seeds.
- Soft-lock probe: 24/24 runs flagged `softlock`.

extrapolated — full mode only).
