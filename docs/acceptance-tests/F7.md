# Acceptance — F7 Packaging: Desktop / Android / Web PWA launch candidates, ShuttleLine multi, BoltPack

**Fabric delivers:** `forge build --target {desktop-linux,desktop-windows,android,web,all}` (`forge/packaging.py`: toolchain discovery, hermetic Godot home, sha256-pinned 4.3-stable templates via `forge templates fetch`, staged keep-import, exports, per-target verify, `BUILD.json`); **PWAPipeline** (`forge/pwa.py`: G-WEB-01 budget, offline service worker, COOP/COEP `_headers`, headless-Chrome smoke); **ShuttleLine** multi-target contract `shuttleline.contract/1` + `generic-folder` adapter (`forge/shuttleline.py`); **BoltPack** CycloneDX SBOM + license audit + `.fabricbolt` (`forge/boltpack.py`). (SPEC §3 Layer A, §4.5, §13 F7)
**Game proves:** `launch-candidates` — Tier 1 (desktop Linux/Windows) + Tier 2 (Android debug APK, Web PWA) builds of the vertical slice, with GAME_SPEC §6.2 gates G-WEB-01, G-SAVE-01, G-NET-01 and G-A11Y-01 (partial). Unsigned / debug builds only (no public release). How-to: [docs/packaging.md](../packaging.md).

## Procedure

```bash
source .venv/bin/activate && uv pip install -e ".[dev,package]"
forge templates fetch                            # once (≈1 GB download, sha256-pinned)
forge accept F7                                  # full: build all targets + platform proofs → results/F7.json
FORGE_ACCEPT_FAST=1 forge accept F7 --no-write   # static subset (pytest / CI, no templates)
pytest -q tests/test_f7_packaging.py
```
