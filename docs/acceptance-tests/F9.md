# Acceptance — F9 LiveOps foundation (readiness only)

**Spec basis.** ASSETFABRIC_SPEC §13 F9 "*post* · LiveOps foundation · **Readiness only**"; §12 gap table "LiveOps
readiness — Remote config / feature flags (launch content deferred)"; GAME_SPEC §5 out of scope "Live seasonal content
(remote config readiness OK)", §8 "Remote config hooks for balance knobs (LiveOps content deferred)", §6.2 **G-NET-01**
"Solo offline launch with networking stack dormant", §4.5 Player State "versioned; migratable". Producer direction
t59u ("then do F8 and F9"). Everything the spec does not pin down is `[INFERENCE F9-n]` in
[INFERENCES.md §F9](../INFERENCES.md); design: [ADR-0022](../adr/0022-liveops-signed-local-config-bundles.md);
operations: [docs/liveops-runbook.md](../liveops-runbook.md).

**Not in F9 (by spec):** a live service, delivery endpoint/CDN, analytics, seasonal content, launch, store listings.

**Fabric delivers:** flag manifest `content/liveops/flags.yaml` → generator kind `liveops` (gates `flags_manifest`,
`knobs_live`, `budget`) → `assets/generated/liveops/liveops.json`; `forge/liveops.py` (manifest, payload rules, RSA
sign/verify, install, roll-forward rollback, device status, PII scrubber + diagnostics schema
`forge/schemas/diag_bundle.schema.json`, readiness checklist); `forge liveops manifest|keygen|bundle|verify|install|
rollback|status|diag-export|readiness`; `forge/save.py classify`; GroundWeave op `gen.liveops`.
**Game proves:** `liveops-readiness` — `autoload/liveops.gd` boots a local state machine (inbox → verify → promote /
reject; active re-verified; crash-loop quarantine), applies kill switches (`Retro.set_profile`, `MusicDirector.set_state`,
`remote_balance`) and balance patches through the F4 LiveChannel validator/overlay; `save.gd` keeps newer saves
read-only; `tools/liveopscheck.gd` reports it all. No network API anywhere.

## Procedure

```bash
source .venv/bin/activate && uv pip install -e ".[dev]"     # dev includes cryptography (forge-side signing only)
forge accept F9                    # → docs/acceptance-tests/results/F9.json (≈ 11 s; Godot 4.3 headless, 25 runs)
forge liveops readiness            # checklist (fails on `fail`; lists `user_gated`)
forge liveops keygen               # dev key → .fabric/liveops/ (gitignored)
forge liveops bundle --serial 1 --flag adaptive_music=off --set enemies.emberling.stats.hp=26 \
    --key .fabric/liveops/dev.key.pem --out /tmp/b1.json
forge liveops install /tmp/b1.json --dir /tmp/dev-liveops
godot --path games/game-zero -- --scene=liveopscheck --liveops-dir=/tmp/dev-liveops \
    --liveops-pubkey=.fabric/liveops/dev.pub.pem --probe=enemies.emberling.stats.hp
forge liveops status --dir /tmp/dev-liveops
pytest -q tests/test_f9_liveops.py
```
