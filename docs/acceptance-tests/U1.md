# U1 — Universal 2D / 2.5D / 3D engine (user request t65u)

* **Command:** `forge accept U1`.
* **Result file:** `docs/acceptance-tests/results/U1.json`.
* **Runner:** `forge/accept_u1.py`.
* **Requirements:** pure Python. Godot is not required. Godot 4.3, Blender 4.3 and OpenSCAD 2021.01 are run headlessly
  when they are installed, and recorded as `ran: false` when they are not.
* **Isolation:** every step uses throw-away directories, so the repo's `.fabric/` state is never touched.
* **Pytest:** `tests/test_game_increments.py::test_increment_acceptance[U1]` runs it in CI (core shard; CI has OpenSCAD
  but no Blender). The fast unit half is `tests/test_universal_engine.py`, 54 tests.
* **Architecture:** `docs/architecture/universal-engine.md`. Decisions: ADR-0023…0026. Inferences: `docs/INFERENCES.md`
  §U1.

**Recorded run:** Linux box, 2026-11-27, `0.9.0+f9` + U1 branch. All tools were present. **PASS** in ≈ 50 s.

## Not claimed

* **Unreal, Unity, RPG Maker, Sprite Lamp/Pro, GameGuru, Clickteam, Construct, CopperCube, Esenthel, AGFPRO,
  AppGameKit, RaySupreme, Fuse, ePic, Flipside, COLMAP/3DGS trainers.** These are `interchange_pack`: we write their
  documented import formats and validate them with our own readers, but **those tools were not run**.
  * They are closed-source or Windows-only, or have no headless mode here.
  * Promoting any of them needs a native check and a real run.
* **FBX, USD, VRM, 3MF, DAE and SPZ** are not written. They are listed as gaps.
* **Creative Engine** is `descriptor_only` because its identity is ambiguous ([INFERENCE U1-8]).
* **Promotions are per machine.** Shipping a promoted recipe as the new baseline is a reviewed commit.
