# ADR-0013 — Product name: AssetFabric (not Asset Factory)

| Field | Value |
|---|---|
| Status | **accepted** |
| Date | 2026-11-05 |
| Deciders | Design chat / Recharged Ideas |

## Context

"Asset Factory" collides with existing third-party AssetFactory products.

## Decision

The product is **AssetFabric**, with fabric-themed tool names (DyeWorks, ShuttleLine, LoomCluster, PocketLoom, PatternVault, BoltPack…).

## Consequences

- Spec text that still says "Factory" (e.g. Factory Lead) refers to the same thing.

## Alternatives considered

- **Asset Factory:** rejected (collision).
