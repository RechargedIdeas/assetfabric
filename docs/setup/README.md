# Setup

1. Python ≥ 3.11, `uv` recommended.  
2. `./scripts/bootstrap.sh` then `source .venv/bin/activate`.  
3. `forge doctor && forge status`.  
4. Optional: install Godot 4.3+ and place binary on PATH or at `godot-bin/godot`.  
5. Run `./scripts/smoke_godot.sh`.

Studio GUI (`PySide6`) is not required for F0.
