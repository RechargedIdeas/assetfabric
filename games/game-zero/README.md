# Game Zero

First product of **AssetFabric** — offline-first 8-bit fighter/farming hybrid on **Godot 4.3, Compatibility renderer**. Design: [`docs/design/GAME_SPEC.md`](../../docs/design/GAME_SPEC.md).

## Run

```bash
# from repo root, Godot 4.3 on PATH (or ./godot-bin/godot)
godot --path games/game-zero                      # play (default scene: sandbox)
godot --headless --path games/game-zero -- --scene=sandbox --autoplay   # headless acceptance
forge accept F1                                   # same, parsed + recorded
```

User args (after `--`): `--scene=<name>`, `--autoplay`, `--boot-only`, `--encounter=<id>`, `--watchdog=<sec>`.

Controls: WASD/arrows move · J/Space attack · R restart (abstract input schema in `autoload/fabric.gd`).

## Layout

| Path | Role |
|---|---|
| `autoload/fabric.gd` | Fabric runtime binding: asset registry, runtime texture/JSON loading, input schema, locales, headless watchdog |
| `assets/generated/` | **Generated by `forge build`** — do not hand-edit. `fabric_assets.json` is the registry |
| `data/` | Encounter/game data (F2+ partly generated by codegen) |
| `sim/` | Deterministic fixed-step simulation (no rendering, no LLM) |
| `scenes/` | Rendering + input scenes driving the sim |
| `locale/` | Locale tables (`tr()` keys only in code) |
